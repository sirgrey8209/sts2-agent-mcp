# 프롬프트 정리 때 반영할 것

채팅 에이전트 프롬프트(`prompts/*.md`)를 다시 정리할 때 한꺼번에 반영할 메모다. 반영하면 항목을 지운다.

## 내부 id를 플레이어에게 보이지 않는다 (2026-11-22)

- `r1c2` 같은 지도 칸 좌표, `c3`·`e1` 같은 전투 id, 선택지 번호는 도구에 넘기는 값일 뿐이다. 채팅 본문에 쓰지 않는다.
- 플레이어에게 가리킬 때는 화면에 그려서 표시하고(`map_route`의 경로·동그라미와 배지), 채팅에서는 그 배지 이름으로 부른다: "A 경로", "2번 칸".
- 카드·유물은 지금처럼 백틱 이름으로 쓴다. 채팅창이 게임에 표시된 이름과 툴팁으로 보여 준다. 같은 이름이 여러 장이면 백틱 안에 전투 id를 쓰고, 채팅창이 이름으로 바꿔 보여 준다.
- 지도 밖(손패, 적, 선택지)을 배지로 가리키는 `point` 도구가 생기면 같은 규칙을 적용한다.

## 앞서 합의했지만 아직 넣지 않은 것

- 기본 상황 설명: 왼쪽 채팅창, 오른쪽 게임 화면. 플레이어는 둘을 함께 보고, 채팅도 하고 게임도 직접 조작한다. 설명은 말보다 화면으로 하고, 게임 화면에 있는 선택은 플레이어가 화면에서 고르게 둔다(2026-11-22 대화의 초안).
- 확인은 조용히(`look`), 설명은 화면을 바꿔서(`show`, `point`). 도구 재설계 뒤 도구 이름에 맞춘다.
- 연속 카드 플레이 표기: 일단 `카드` → `카드` → 턴 종료.
- 질문: 입력창 자리에 뜨는 짧은 선택지(`ask`, 라벨만, 질문 하나). 근거는 질문 전에 본문으로 짧게.
