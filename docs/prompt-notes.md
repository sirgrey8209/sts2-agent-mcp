# 프롬프트 정리 때 반영할 것

채팅 에이전트 프롬프트(`prompts/*.md`)에 아직 넣지 않은 메모다. 반영하면 항목을 지운다.

구성(2026-11-22): `system`(상황, 설명 방식, 이 세션, 화면별 지침) + `persona` + 플레이 단계 + `character-<id>` + `prefs`. 모두 경어체로 쓴다. 세션은 런마다 하나다(관제 세션 없음).

## 내용이 정해지면 채울 것

- `persona.md`: 말투와 성격.
- `character-<id>.md`: 캐릭터별 팁(id는 게임 id 소문자: ironclad, silent, defect, necrobinder, regent 등).
