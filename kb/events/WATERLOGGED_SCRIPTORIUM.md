# 물에 잠긴 기록실 (WATERLOGGED_SCRIPTORIUM)

**요약**: 최대 체력 6을 무료로 얻거나, 골드 55로 카드 1장 / 골드 99로 카드 2장에 인챈트 '안정'(`Steady`, 보존 부여)을 건다.

## 조건
- 1막 `Underdocks` 이벤트.
- 모든 플레이어의 골드가 55 이상이어야 등장한다.
- 개별 이벤트(공유 아님).

## 선택지
| 선택지 | 효과 |
|---|---|
| 핏빛 잉크 (`BLOODY_INK`) | 최대 체력 +6. 이벤트 종료 |
| 촉수 펜 (`TENTACLE_QUILL`) | 골드 55 지불 → 카드 1장 선택해 `Steady` 인챈트. 이벤트 종료. 골드 55 미만이면 잠김 |
| 꺼끌꺼끌한 스펀지 (`PRICKLY_SPONGE`) | 골드 99 지불 → 카드 2장 선택해 `Steady` 인챈트. 이벤트 종료. 골드 99 미만이면 잠김 |

## 결과 상세
- `Steady`(안정): 인챈트된 카드에 보존(Retain) 키워드를 붙인다. 다른 효과는 없다.
- 인챈트 대상: 상태이상·저주·퀘스트 카드, 사용 불가 카드, 이미 다른 인챈트가 붙은 카드는 고를 수 없다.
- 골드는 카드 선택 전에 먼저 지불된다.

## 플레이 메모
- 보존이 의미 있는 카드(비싼 파워, 상황용 카드)가 없다면 최대 체력 6이 무난하다.
