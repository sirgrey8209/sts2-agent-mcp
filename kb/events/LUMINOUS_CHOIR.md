# 빛나는 합창단 (LUMINOUS_CHOIR)

**요약**: 카드 2장을 제거하고 저주 '포자 잠식'(`SporeMind`)을 받거나, 골드 100~149를 내고 무작위 유물 1개를 얻는다.

## 조건
- 1막(`Overgrowth`) 이벤트.
- 모든 플레이어가 골드 149 이상이고, 아직 얻을 수 있는 유물이 남아 있어야 등장.
- 비공유 이벤트.

## 선택지
| 선택지 | 효과 |
|---|---|
| 버섯의 살에 다가간다 (`REACH_INTO_THE_FLESH`) | 덱에서 카드 2장을 골라 제거 → 덱에 `SporeMind` 추가. 이벤트 종료 |
| 공물을 바친다 (`OFFER_TRIBUTE`) | 골드 지불(100~149) → 무작위 유물 1개 획득. 이벤트 종료 |
| 잠김 (`OFFER_TRIBUTE_LOCKED`) | 골드가 부족할 때 대신 표시. 선택 불가 |

## 결과 상세
- 공물 비용은 이벤트가 열릴 때 149에서 0~49를 빼서 정해진다(화면 표시값이 실제 값). 등장 조건이 골드 149 이상이므로 사실상 항상 낼 수 있다.
- 유물 희귀도: 일반 50%, 고급 33%, 희귀 17%(`RelicFactory.RollRarity`). 플레이어 유물 주머니 앞에서 꺼내므로 이후 다시 나오지 않는다.
- **포자 잠식(`SporeMind`)**: 비용 1, 소멸 저주. 사용 시 아무 효과 없이 소멸한다. 강화 불가.

## 플레이 메모
- 포자 잠식은 에너지 1로 소멸시킬 수 있는 저주라서 실질 부담이 작다. 카드 2장 제거를 원하면 좋은 선택이다.
