# 전투로 손상된 훈련 인형 (BATTLEWORN_DUMMY)

**요약**: 체력 75 / 150 / 300인 훈련 인형 중 하나를 골라 3턴 안에 처치하면 각각 포션 1개 / 무작위 카드 2장 강화 / 유물 1개를 얻는다. 인형은 공격하지 않는다.

## 조건
- 3막 영광(`Glory`) 이벤트.
- 별도 등장 조건 없음.
- 공유 이벤트(멀티플레이에서 모두가 같은 이벤트·같은 전투를 진행).

## 선택지
| 선택지 | 효과 |
|---|---|
| 1로 설정 (`SETTING_1`) | 전투 친구 V1.0(`BATTLE_FRIEND_V1`, 체력 75)과 전투. 처치 시 무작위 포션 1개 |
| 2로 설정 (`SETTING_2`) | 전투 친구 V2.0(`BATTLE_FRIEND_V2`, 체력 150)과 전투. 처치 시 덱의 무작위 강화 가능 카드 2장 강화 |
| 3으로 설정 (`SETTING_3`) | 전투 친구 V3.0(`BATTLE_FRIEND_V3`, 체력 300)과 전투. 처치 시 유물 1개 |

## 결과 상세
- 전투: 설정별로 `BATTLEWORN_DUMMY_EVENT_V1_ENCOUNTER` / `BATTLEWORN_DUMMY_EVENT_V2_ENCOUNTER` / `BATTLEWORN_DUMMY_EVENT_V3_ENCOUNTER`(일반 몬스터 방 취급). 일반 전투 보상(골드·카드 등)은 없다(`ShouldGiveRewards = false`). 전투 후 이벤트로 돌아와 결과가 처리된다.
- 인형의 행동은 '가만히 있기'(`NOTHING_MOVE`) 하나뿐이며 아무것도 하지 않는다.
- 인형은 시작 시 시간 제한(`BattlewornDummyTimeLimitPower`) 3을 얻는다. 적 턴이 끝날 때마다 1씩 줄고, 1인 상태에서 적 턴이 끝나면 인형이 도망친다. 즉 플레이어 턴 3번 안에 처치해야 한다.
  - 도망치면 패배 페이지(`DEFEAT`)로 끝나고 보상이 없다. 체력 손실 등 다른 불이익도 없다.
- 멀티플레이: 인형 체력 = 기본 체력 × 플레이어 수 × 멀티플레이 보정(`MultiplayerScalingModel`, 막 기준). 선택지에 표시되는 체력이 실제 값. 싱글은 75/150/300 그대로. 승천 보정 없음.
- 처치 보상:
  - 설정 1: 내 캐릭터 포션 풀 + 공용 포션 풀(해금된 것)에서 무작위 포션 1개를 보상 화면으로 제시.
  - 설정 2: 덱의 강화 가능한 카드 중 무작위 2장을 즉시 강화.
  - 설정 3: 유물 주머니 맨 앞의 유물 1개를 보상 화면으로 제시(`RelicFactory.PullNextRelicFromFront`).
  - 처치 시 전투 중 카드·파워 효과로 쌓인 추가 보상(`ExtraRewards`, 예: 사냥(`TheHunt`), 금지된 마도서(`ForbiddenGrimoirePower`))도 위 보상과 함께 같은 보상 화면에 제시된다. 제시할 보상이 하나도 없으면 보상 화면은 열리지 않는다.

## 플레이 메모
- 3턴 동안 받는 피해가 없으므로, 3턴 총 피해량으로 처치 가능한 가장 높은 설정을 고른다(싱글 기준 턴당 평균 25 / 50 / 100).
- 실패해도 손해가 없으니 애매하면 높은 설정에 도전해도 된다. 다만 전투 중 쓴 포션·소모 효과는 그대로 소비된다.
