# 탄스 (TANX)

**요약**: 3막 시작 지점의 고대의 존재. 입장 시 체력을 회복시켜 주고, 무기 계열 고대 유물 9종(조건부 10종) 중 무작위 3개를 제시해 1개를 고르게 한다.

## 조건
- 3막(`Glory`)의 고대의 존재 후보(`Nonupeipe`, `Tanx`, `Vakuu`, 그리고 런 시작 때 무작위로 배분되는 공용 고대 존재) 중 무작위 1명이 그 막의 시작 지점(고대 노드)에 배치된다. 해금 조건 없음.

## 선택지
| 선택지 | 효과 |
|---|---|
| 제시된 유물 3개 중 하나 | 해당 고대 유물 획득. 이벤트 종료 |

후보 풀(여기서 무작위로 섞어 3개를 제시, 중복 없음):

| 유물 | 효과 |
|---|---|
| 클로 (`Claws`) | 획득 시 덱에서 0~6장을 골라 `할퀴기`(`Maul`)로 변화. 강화된 카드는 강화된 할퀴기가 되고, 인챈트는 옮겨 붙을 수 있으면 유지. 취소 불가(확인 필요) |
| 크로스보우 (`Crossbow`) | 내 턴 시작마다 자기 캐릭터 카드 풀의 무작위 공격 카드 1장을 손으로. 그 턴 동안 비용 0 |
| 쇠몽둥이 (`IronClub`) | 카드를 4장 사용할 때마다 1장 뽑음. 사용 횟수는 전투가 바뀌어도 이어서 센다 |
| 고기 써는 칼 (`MeatCleaver`) | 휴식처에 '요리' 추가: 덱에서 카드 2장 제거 + 최대 체력 +5. 제거 가능한 카드가 2장 이상일 때만 가능 |
| 사이 (`Sai`) | 내 턴 시작마다 방어도 7(민첩 등 보정 없음) |
| 가시 박힌 건틀릿 (`SpikedGauntlets`) | 최대 에너지 +1. 전투 중 파워 카드 비용 +1 |
| 탄스의 호각 (`TanxsWhistle`) | 획득 시 덱에 `호각 불기`(`Whistle`) 1장 추가: 비용 3 공격, 피해 33, 적 기절, 소멸 |
| 투척용 도끼 (`ThrowingAxe`) | 매 전투 처음 사용하는 카드가 1번 추가로 사용됨 |
| 전투용 망치 (`WarHammer`) | 엘리트 전투 승리마다 덱의 강화 가능한 카드 중 무작위 4장 강화 |
| 삼단 부메랑 (`TriBoomerang`) | **덱에 `본능`을 인챈트할 수 있는 공격 카드가 3장 이상일 때만 후보에 추가.** 획득 시 공격 카드 3장을 골라 `본능`(`Instinct`) 인챈트: 공격 피해 ×2 |

## 결과 상세
- 입장 시 회복: 잃은 체력을 전부 회복한다. 승천 2 이상(`WearyTraveler`)이면 잃은 체력의 80%만 회복한다. 이 회복은 선택과 무관하게 먼저 일어난다.
- 건너뛰는 선택지는 없다.
- `본능` 대상: 덱에서 사용불가가 아니고 인챈트가 없는 공격 카드.
- 대사(캐릭터별·방문 횟수별)는 연출뿐이며 효과에 영향이 없다.

## 플레이 메모
- 3막은 보스까지 남은 전투가 많지 않다. 즉시 효과(클로, 삼단 부메랑, 호각)나 매 턴 효과(사이, 크로스보우, 건틀릿)가 엘리트 의존 유물(전투용 망치)보다 체감이 크다.
- 가시 박힌 건틀릿은 파워 위주 덱에는 손해일 수 있다.
