# DeprecatedAncientEvent (DEPRECATED_ANCIENT_EVENT)

**요약**: 더 이상 쓰이지 않는 고대 존재 이벤트의 자리표시자. 선택지가 없고 대화 정의도 구현되어 있지 않다. 어떤 막의 고대 존재 목록에도, 공용 고대 존재 목록에도 들어 있지 않아 정상 플레이에서는 등장하지 않는다(사라진 이벤트를 저장 데이터에서 대체하는 용도로 보이나 코드상 불명확).
