# 테즈카타라 (TEZCATARA)

**요약**: 2막 시작 지점의 고대의 존재. 입장 시 체력을 회복시켜 주고, 세 묶음에서 1개씩 뽑은 고대 유물 3개 중 1개를 고르게 한다.

## 조건
- 2막(`Hive`)의 고대의 존재 후보(`Orobas`(해금 필요), `Pael`, `Tezcatara`, 그리고 런 시작 때 무작위로 배분되는 공용 고대 존재) 중 무작위 1명이 그 막의 시작 지점(고대 노드)에 배치된다.

## 선택지
세 칸이 각각 다른 묶음에서 균등 확률로 1개씩 정해진다. 하나를 골라 획득하면 이벤트 종료.

| 칸 | 유물 | 효과 |
|---|---|---|
| 1 | 엄청 뜨거운 코코아 (`VeryHotCocoa`) | 매 전투 첫 턴 시작 시 에너지 +4 |
| 1 | 냠냠 쿠키 (`YummyCookie`) | 획득 시 덱에서 카드 4장을 골라 강화 |
| 1 | 영양만점 수프 (`NutritiousSoup`) | **덱에 기본 등급 타격이 있을 때만 1번 칸 후보에 추가.** 획득 시 인챈트 가능한 기본 타격 전부에 `테즈카타라의 잉걸불`: 비용 0으로 고정, 피해 +3, 영구(제거·변화 불가) |
| 2 | 찌이인한 포옹 (`BiiigHug`) | 획득 시 덱에서 카드 4장 제거. 전투 중 뽑을 카드 더미를 섞을 때마다 `그을음`(사용불가 상태이상) 1장을 뽑을 카드 더미 무작위 위치에 추가 |
| 2 | 동화책 (`Storybook`) | 획득 시 덱에 `찬란한 불꽃` 1장 추가(비용 0 스킬: 에너지 2, 카드 2장 뽑기, 최대 체력 1 잃음) |
| 2 | 따뜻한 장갑 (`ToastyMittens`) | 매 턴 시작 시 카드를 뽑은 직후 손패에서 카드 1장을 골라 소멸(필수), 힘 +1 |
| 3 | 황금 나침반 (`GoldenCompass`) | 획득 즉시 현재 막(2막) 지도를 외길로 교체. 이 막의 '?' 노드는 항상 이벤트 |
| 3 | 호박 양초 (`PumpkinCandle`) | 불이 켜져 있는 동안 최대 에너지 +1. 전투 5번 끝나면 꺼짐. 휴식처에 생기는 다시 불 붙이기 선택지(`KindleRestSiteOption`)로 5회 추가 |
| 3 | 장난감 상자 (`ToyBox`) | 획득 시 밀랍 유물 5개를 보상 화면으로 받음(일반 유물 풀에서 무작위 등급). 전투 3번마다 가장 왼쪽의 녹지 않은 밀랍 유물이 녹아 사라짐(15전투 후 소진) |
| 3 | 황금 인장 (`SealOfGold`) | 내 턴 시작마다 골드가 3 이상이면 골드 3을 내고 에너지 +1 |

## 결과 상세
- 입장 시 회복: 잃은 체력을 전부 회복한다. 승천 2 이상(`WearyTraveler`)이면 잃은 체력의 80%만 회복한다. 선택과 무관하게 먼저 일어난다.
- 건너뛰는 선택지는 없다.
- 황금 나침반의 외길(싱글플레이): 고대 → 일반 전투 → ? → 일반 전투 → 휴식 → 일반 전투 → 휴식 → ? → 보물 → ? → 보물 → ? → 상점 → 엘리트 → 휴식 → 엘리트 → 휴식 → 보스. 멀티플레이에서는 세 번째 칸(두 번째 일반 전투)이 빠진다.
- 영양만점 수프의 대상은 '기본 등급 + 타격 태그'이며 이미 인챈트가 있는 카드는 제외된다.
- 대사는 연출뿐이다(디펙트에게는 '모든 캐릭터용' 우호적 대사가 나오지 않음).

## 플레이 메모
- 황금 나침반은 일반 전투 3번, 엘리트 2번, 휴식 4번, 보물 2번, 이벤트 4번, 상점 1번으로 경로가 고정된다. 경로 선택권은 사라지지만 휴식과 보물이 많다.
- 장난감 상자의 밀랍 유물은 결국 모두 사라진다. 약 15전투 동안만 쓰는 유물 5개로 생각한다.
