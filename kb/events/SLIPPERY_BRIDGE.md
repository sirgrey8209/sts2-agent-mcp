# 미끄러운 다리 (SLIPPERY_BRIDGE)

**요약**: 무작위로 지정된 카드 1장을 덱에서 제거하고 끝내거나, 체력을 잃고(3, 4, 5, … 점점 증가) 제거될 카드를 다른 카드로 다시 뽑는다. 버티기는 횟수 제한 없이 반복 가능.

## 조건
- 막 공용 이벤트 풀(`ModelDb.AllSharedEvents`)에 속한다.
- 런 전체 층수(`TotalFloor`)가 7층 이상일 때만 등장한다.
- 모든 플레이어의 덱에 제거 가능한 카드가 1장 이상 있어야 한다.

## 선택지
| 선택지 | 효과 |
|---|---|
| 헤쳐 나간다 (`OVERCOME`) | 현재 지정된 카드를 덱에서 제거. 이벤트 종료 |
| 버틴다 (`HOLD_ON_*`) | 체력 손실(방어 무시, 보정 없음) → 지정 카드를 새로 뽑음 → 같은 두 선택지가 다시 나옴 |

## 결과 상세
- 버티기 체력 손실: 3 + 지금까지 버틴 횟수. 1번째 3, 2번째 4, 3번째 5, … 상한 없음.
- 처음 지정 카드: 덱에서 기본(`Basic`) 등급이 아닌, 제거 가능한 카드 중 무작위.
- 버틸 때 새 지정 카드: 직전 지정 카드와 **다른 종류(카드 id)** 이고, 이번 이벤트에서 이미 지정됐던 카드가 아닌 제거 가능한 카드 중 무작위. 이때는 기본 카드도 후보가 된다.
- 후보가 하나도 없으면 덱의 제거 가능한 카드 전체에서 다시 뽑는다(이미 지정됐던 카드 포함).
- 선택지에 지정 카드가 표시되므로 무엇이 제거될지 보고 고를 수 있다.
- 버티기 페이지 문구는 7번째부터 같은 문구(`HOLD_ON_LOOP`)가 반복될 뿐 효과는 같다.

## 플레이 메모
- 처음엔 기본 카드가 아닌 카드(대체로 좋은 카드)가 지정된다. 버티면 타격·수비 같은 기본 카드가 지정될 수 있으므로, 체력 몇을 내고 원치 않는 카드가 나올 때까지 돌리는 것이 일반적이다.
- 누적 손실은 n번 버티면 3+4+…+(n+2). 3번이면 12, 5번이면 25.
