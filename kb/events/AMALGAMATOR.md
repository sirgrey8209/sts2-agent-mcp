# 융합자 (AMALGAMATOR)

**요약**: 기본 타격 2장을 제거하고 궁극의 타격(`UltimateStrike`) 1장을 얻거나, 기본 수비 2장을 제거하고 궁극의 수비(`UltimateDefend`) 1장을 얻는다.

## 조건
- 2막 군락(`Hive`) 이벤트.
- 모든 플레이어가 덱에 제거 가능한 기본(Basic 등급) 타격 태그 카드 2장 이상, 기본 수비 태그 카드 2장 이상을 가지고 있어야 등장한다.
- 공유 이벤트 아님.

## 선택지
| 선택지 | 효과 |
|---|---|
| 타격을 합친다 (`COMBINE_STRIKES`) | 덱에서 기본 타격 2장을 골라 제거 → `UltimateStrike` 1장을 덱에 추가. 이벤트 종료 |
| 수비를 합친다 (`COMBINE_DEFENDS`) | 덱에서 기본 수비 2장을 골라 제거 → `UltimateDefend` 1장을 덱에 추가. 이벤트 종료 |

## 결과 상세
- 선택 대상은 '타격'/'수비' 태그가 있고, 등급이 Basic이며, 제거 가능한 카드뿐이다. 강화된 기본 타격·수비도 대상이다(강화 여부는 조건에 없음).
- 새로 얻는 카드는 강화되지 않은 상태로 추가된다(제거한 카드의 강화는 이어지지 않음).
- `UltimateStrike`: 비용 1 공격, 적 하나에 피해 14(강화 +6 → 20). 타격 태그 보유. 등급 Uncommon.
- `UltimateDefend`: 비용 1 스킬, 방어도 11(강화 +4 → 15). 수비 태그 보유. 등급 Uncommon.

## 플레이 메모
- 덱 장수가 1장 줄고 카드 하나의 효율이 2배 이상이 된다. 강화된 기본 카드를 넣으면 강화가 사라지므로 강화되지 않은 카드를 고르는 편이 손해가 적다.
