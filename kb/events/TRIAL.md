# 재판 (TRIAL)

**요약**: 재판관을 맡으면 피고 3종 중 하나가 무작위(각 1/3)로 나오고, 유죄/무죄 판결마다 정해진 보상과 저주를 받는다. 거절을 끝까지 고집하면 런을 포기하는 확인창이 뜬다.

## 조건
- 3막(`Glory`) 이벤트. 별도 등장 조건 없음.
- 개별 이벤트(공유 아님).

## 선택지
| 선택지 | 효과 |
|---|---|
| 수락한다 (`ACCEPT`) | 피고 3종 중 무작위 1종의 재판 페이지로 |
| 거절한다 (`REJECT`) | 다음 페이지: '수락한다' 또는 '완강하게 거절한다' |
| └ 수락한다 (`ACCEPT`) | 위 '수락한다'와 같음 |
| └ 완강하게 거절한다 (`DOUBLE_DOWN`) | 런 포기 확인창을 띄운다. 확인하면 런이 포기(종료)된다 |

피고별 판결:
| 피고 | 판결 | 효과 |
|---|---|---|
| 상인 (`MERCHANT`) | 유죄 (`GUILTY`) | 저주 `Regret`(후회) 추가 → 무작위 유물 2개 |
| 상인 | 무죄 (`INNOCENT`) | 저주 `Shame`(수치) 추가 → 덱에서 카드 2장 선택해 강화 |
| 귀족 (`NOBLE`) | 유죄 | 체력 10 회복 |
| 귀족 | 무죄 | 저주 `Regret`(후회) 추가 → 골드 300 |
| 평범한 여자 (`NONDESCRIPT`) | 유죄 | 저주 `Doubt`(의심) 추가 → 카드 보상 2개(각 3장 중 1장, 일반 확률) |
| 평범한 여자 | 무죄 | 저주 `Doubt`(의심) 추가 → 덱에서 카드 2장 선택해 무작위 변화 |

모든 판결 후 이벤트 종료.

## 결과 상세
- 유물은 등급을 일반 50% / 고급 33% / 희귀 17%로 굴려 유물 풀 앞에서 꺼낸다(2번 각각).
- 강화·변화 선택은 정확히 2장(덱에 가능한 카드가 그보다 적으면 가능한 만큼).
- 저주 효과:
  - `Regret`(후회): 사용 불가. 손에 있는 채로 내 턴이 끝나면, 그 시점 손패 장수만큼 체력을 잃는다(방어 무시).
  - `Shame`(수치): 사용 불가. 손에 있는 채로 턴이 끝나면 손상(`FrailPower`) 1을 얻는다.
  - `Doubt`(의심): 사용 불가. 손에 있는 채로 턴이 끝나면 약화(`WeakPower`) 1을 얻는다.
  - 셋 모두 강화 불가. 손상·약화가 새로 걸린 경우 다음 지속시간 감소 1회를 건너뛰어 다음 턴에도 적용된다.
- 피고 번호(`EntrantNumber`)는 101~998 사이 연출용 숫자로 효과 없음.

## 플레이 메모
- 귀족 유죄는 저주 없이 체력 10 회복이라 가장 안전하다. 귀족 무죄는 골드 300과 후회를 맞바꾼다.
- 후회는 손패가 많을수록 아프므로 손패를 많이 들고 턴을 끝내는 덱에는 부담이 크다.
- '완강하게 거절한다'는 런을 포기시키므로 절대 고르지 않는다.
