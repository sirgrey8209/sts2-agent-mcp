# 지식의 악마 (KNOWLEDGE_DEMON)

**요약**: 2막(`Hive`) 보스. 4턴마다 '지식의 저주'로 영구 디버프 둘 중 하나를 강제로 고르게 하며(최대 3번), 숙고로 체력 30을 회복하고 힘을 얻는다.

## 기본
- HP: 379 (A8+ 399)
- 등장: 2막(`Hive`) 보스 '지식의 악마' (`ENCOUNTER.KNOWLEDGE_DEMON_BOSS`), 단독
- 시작 시 특별한 능력 없음

## 행동
| 행동 | 의도 | 효과 |
|---|---|---|
| 지식의 저주 (`CURSE_OF_KNOWLEDGE_MOVE`) | 디버프 | 각 플레이어가 카드 2장 중 1장을 반드시 골라 즉시 효과를 받는다(아래 표). 사용 횟수 +1 |
| 때리기 (`SLAP_MOVE`) | 공격 | 피해 17 (A9+ 18) |
| 압도적인 지식 (`KNOWLEDGE_OVERWHELMING_MOVE`) | 공격 ×3 | 피해 8 (A9+ 9) × 3회 |
| 숙고 (`PONDER_MOVE`) | 공격 + 회복 + 버프 | 피해 11 (A9+ 13) → 자신 체력 30 × 플레이어 수 회복 → 자신 힘 +2 (A9+ +3) |

### 지식의 저주 선택지
건너뛸 수 없다. 고른 카드는 덱에 들어가지 않고, 해당 능력이 플레이어에게 바로 적용된다.

| 회차 | 선택 A | 선택 B |
|---|---|---|
| 1번째 | `Disintegration` 6 | `MindRot`: 턴 시작 드로우 -1 |
| 2번째 | `Disintegration` 7 | `Sloth`: 한 턴에 카드 3장까지만 사용 가능 |
| 3번째 | `Disintegration` 8 | `WasteAway`: 최대 에너지 -1 |

- **`DisintegrationPower`**: 플레이어 턴이 끝날 때마다 수치만큼 피해(방어도로 막을 수 있음, 힘·약화 보정 없음). 여러 번 고르면 수치가 합산된다(최대 6+7+8=21).
- **`MindRotPower`**: 손패 드로우 수가 수치만큼 줄어든다(0 미만은 안 됨).
- **`SlothPower`**: 턴마다 낸 카드 수가 수치(3)에 도달하면 더 이상 카드를 낼 수 없다. 내 턴 시작마다 카운트 초기화.
- **`WasteAwayPower`**: 최대 에너지가 수치만큼 줄어든다.
- 모두 전투 동안 지속된다.

## 패턴
- 시작: 지식의 저주.
- 고정 순환: 지식의 저주 → 때리기 → 압도적인 지식 → 숙고 → (분기)
- 분기: 지식의 저주를 쓴 횟수가 3 미만이면 지식의 저주, 3 이상이면 때리기로 간다.
- 즉 1·5·9턴째에 저주, 이후로는 때리기 → 압도적인 지식 → 숙고 3행동 순환.
- 무작위 요소 없음.

## 특수 규칙
- 숙고의 회복량은 플레이어 수에 비례한다(1인 30, 2인 60 …).

## 플레이 메모
- `Disintegration`은 매 턴 방어도로 막을 수 있는 피해라 방어가 넉넉한 덱에는 가벼운 선택이다. 드로우/카드 수/에너지 제한은 덱 성능 자체를 깎는다. 덱의 성격에 따라 고른다.
- 숙고가 처음 세 번은 4턴마다, 지식의 저주 3회 이후에는 3턴마다(때리기 → 압도적인 지식 → 숙고) 30을 회복하고 힘을 쌓으므로 장기전이 될수록 불리하다. 숙고 직전에 피해를 몰아넣어도 회복은 피할 수 없다.
- 로컬라이즈에 있는 `BLUE_FLAME`, `HAVE_A_TASTE` 행동 이름은 현재 코드에서 쓰이지 않는다.
